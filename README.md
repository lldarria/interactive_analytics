# interactive_analytics

Repository with laboratory works completed for the course "Systems and Tools of Interactive Analytics".

## Contents

- Lab 1 - Design and implementation of a relational database structure.
- Lab 2 - Database normalization and transformation to the Third Normal Form.
- Lab 3 - Development and execution of basic SQL queries.
- Lab 4 - Advanced SQL techniques, regular expressions, and data analysis.

## Technologies 

- SQL
- MySQL
- Relational databases
